# 03_UX_REGELN

## Ziel

Dieses Dokument definiert die verbindlichen UX-Regeln für WUXUAI Bonus.

## Grundprinzipien

### Eine Seite = Eine Entscheidung

Jeder Bildschirm verfolgt genau ein Ziel.

### Mobile First

Zuerst für Smartphones entwerfen, danach Tablet und Desktop.

### Installationsassistent

Das Onboarding fühlt sich wie ein Einrichtungsassistent an, nicht wie
ein Formular.

### Autosave

Jede Änderung wird automatisch gespeichert. Kein manueller
Speichern-Button.

### Wenig Text

Icons und klare Begriffe statt langer Erklärungen.

### Keine technischen Begriffe

Betreiber sollen keine Entwicklerbegriffe sehen.

### Dashboard

Dashboard beantwortet: - Wie läuft mein Bonusprogramm? - Was ist heute
passiert? - Was soll ich als Nächstes tun?

### Starter Kit

Im Onboarding gibt es nur einen Hauptdownload: Starter Kit.

### Branchenneutrale Sprache

Allgemeine sichtbare Produkttexte verwenden Unternehmen, Geschäft, Betreiber,
Teammitglied und Kunde. Branchenspezifische Begriffe bleiben erlaubt, wenn sie
echte Inhalte oder Beispiele bezeichnen.

### Auswahlfelder

Definierte Optionslisten werden als verständliche, barrierefreie Dropdowns
oder Comboboxen dargestellt. Sie sind tastaturbedienbar, Mobile-Safari-tauglich
und besitzen mindestens 44 px hohe Touchflächen. Branchenabhängige Optionen
werden zentral konfiguriert und zeigen keine ungeeigneten Optionen anderer
Branchen.

### Konsistenz

Alle Karten: - gleiche Höhe - gleiche Abstände - responsive - keine
abgeschnittenen Texte

### Deutsch

Alle sichtbaren Texte in V1 sind Deutsch.
